# howlback.app

The Howlback website. Netlify publishes this folder automatically on every push to main.

Pages are generated by src/build.py from shared pieces:
- src/parts.json: hero, signup band, footer, share box
- src/posts.json: the stories
- src/base.css + src/extra.css -> style.css
- site.js: listings data (resources, clinics, rescues) and page behavior
- src/mockups.html: app phone mockups (rendered to img/app/*.webp)

After editing, run python3 src/build.py and commit the generated files.
